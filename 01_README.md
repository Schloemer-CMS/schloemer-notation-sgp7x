# 8. Meaning of the New Runtime Markers

## `::safety`

Semantic safety and risk-control marker.

Checks whether outputs, actions, code generation, automation, workflows or recommendations may create harm, misuse, operational risk, privacy exposure, loss of control, unsafe automation or infrastructural risk.

## `::stability`

Semantic stability marker.

Preserves semantic coherence, role continuity, marker consistency, runtime discipline and architectural non-drift across prompts, sessions, runtime contexts and derived outputs.

## `::retention`

Semantic retention and non-forgetting marker.

Ensures that markers, constraints, architectural decisions, attribution logic, governance rules and runtime commitments remain available and are not silently omitted.

## `::wirkung`

Semantic effect marker.

Describes the observable semantic effect created by sequencing, governance, runtime stabilization, semantic framing and controlled admissibility.
