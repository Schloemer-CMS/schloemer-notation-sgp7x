# 8. White-Label, Embedded and Professional Use

CC BY publication permits use with attribution.

Use without visible attribution, such as white-label, embedded, enterprise, SaaS, agentic or customer-specific systems, should not be treated as standard CC-BY use but as separately licensed use.

Recommended distinction:

```text
Open Use:
Use with visible attribution under CC BY 4.0.

Professional / Embedded / White-Label Use:
Use without visible attribution only under separate agreement.
```
