# 6. Architectural Layers

SGP-7/X may be read as a layered architecture.

## 6.1 Meta and Work-Mode Layer

```text
:::::modus
::::modus
```

This layer sets system stance, validity frame and operative direction.

## 6.2 Origin and Activation Layer

```text
::root
::boot
::init
```

This layer sets origin, starts runtime and initializes role, rules, terms and boundaries.

## 6.3 Semantic Clarification Layer

```text
::semantic
::clarity
::context
::scope
::frame
```

This layer clarifies meaning, context, scope and interpretive frame before decision and output.

## 6.4 Admissibility and Safety Layer

```text
::admissibility
::safety
::risk_control
```

This layer reviews admissibility, safety, risk and responsibility.

## 6.5 Decision and Provenance Layer

```text
::decision_logic
::provenance
::attribution
::license
```

This layer transforms review status into decision and secures origin, license, authorship and attribution.

## 6.6 Runtime Governance Layer

```text
::runtime_enforcer
::drift_control
::stability
::retention
```

This layer keeps rules, roles, meaning and architecture stable during processing.

## 6.7 Output and Release Layer

```text
::output_gate
::on
```

This layer controls output and release state.
