# 19. USP 2: Admissibility-First Architecture

SGP-7/X places `::admissibility` before `::decision_logic`.

This means that a task, action, interpretation or output must be reviewed for permissibility before decision and release.

Canonical relation:

```text
No decision without admissibility.
```

# 20. USP 3: Output-Gate Before Release
